Detailed Description

Header file for command processor module for smart sensor node.

This module processes commands received via UART for a smart sensor node that measures temperature, relative humidity, and CO2 levels.

◆ cmdProcessor()

int cmdProcessor ( void  )

Processes the chars in the RX buffer looking for commands.abort.

Supported commands:
A reads the real-time values of the variables provided by the sensor
P reads the real-time value of one of the sensors
L returns the last 20 samples of each variable
R resets the history

Returns
0: if a valid command was found and executed
-1: if empty string or incomplete command found
-2: if an invalid command was found
-3: if a CS error is detected (command not executed)
-4: if string format is wrong
